# Quiz authoring

1. Get the quiz's structure first, and write one question per slot.
2. Test understanding: ask why or what happens, not only what something is called.
3. Give each question two to four rubric points that can each be checked alone.
4. Pin the rubric before showing the question.
5. To grade, judge each point separately, and explain what was missed rather than only the mark.
