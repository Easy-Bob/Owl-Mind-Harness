# Quiz authoring

1. Write at most 5 questions, each with exactly 4 options (A to D).
2. Test understanding: ask why or what happens, not only what something is called.
3. Make every wrong option plausible, and keep each option under 200 characters.
4. Give 1 to 3 correct letters. Use more than one only when several options are truly correct.
5. Post the quiz with one post_quiz call. Code adds the answers at the end, so don't write them.
