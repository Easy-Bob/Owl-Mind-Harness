# Study planning

1. Find the goal and the date, and ask if either is missing.
2. Check which topics are due for review, and put overdue topics first.
3. Order new topics so that prerequisites come before what depends on them.
4. Keep it realistic: fewer topics finished beats many topics started.
5. Save it as a proposal, and tell the student they can change it.
